# Filter transaksi harian

Tabel menampilkan seluruh transaksi aktif secara default, dengan pagination yang sudah ada dan urutan input terbaru (`createdAt` menurun). Filter tidak lagi otomatis membatasi ke hari ini. Setelah simpan, daftar kembali ke semua tanggal dengan urutan input terbaru.

Filter Dari–Sampai tersedia di dalam bagian Transaksi harian. Kedua batas bersifat inklusif dan dapat dikosongkan untuk rentang terbuka. Tombol Hari ini memilih hari lokal perangkat, sedangkan Semua tanggal menghapus batas. Pencarian digabungkan dengan filter tanggal. Tanggal akhir sebelum tanggal awal menampilkan pesan dan menonaktifkan unduhan.

Ringkasan penjualan dan unduhan Excel/PDF menggunakan hasil filter yang sama. Periode dan nama berkas mencantumkan rentang; Download History menyimpan periode tersebut. Filter persediaan harian dan kartu Total stock seluruh hari tidak terpengaruh.
